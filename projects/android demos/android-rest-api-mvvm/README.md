# Android REST API + MVVM

**Step 3 — REST API Integration**

Portfolio demonstration of a modern Android application using Kotlin, Retrofit, REST APIs, and MVVM-oriented architecture.

## Demonstrates
- Retrofit API integration
- Repository pattern
- ViewModel state management
- Loading, success, empty, and error states
- Network error handling
- Clean separation between UI, data, and business logic

## Architecture

API → Repository → ViewModel → UI

> Portfolio demonstration. It does not contain proprietary employer code.
