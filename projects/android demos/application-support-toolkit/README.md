# Application Support Toolkit

**Step 6 — Application Support & Troubleshooting**

A practical documentation and troubleshooting portfolio for Application Support Engineer and Application Analyst roles.

## Topics
- Incident troubleshooting
- Android crash analysis
- Log analysis
- REST API troubleshooting
- Firebase Crashlytics investigation
- Database troubleshooting
- HTTP status codes
- Root cause analysis (RCA)
- Production incident checklists
- Fix verification and documentation

## Example troubleshooting flow

1. Reproduce the issue
2. Collect logs and error details
3. Identify the affected component
4. Check API/database/application behavior
5. Determine root cause
6. Document and apply the fix
7. Validate the solution
8. Record preventive actions

> This repository is a portfolio demonstration of troubleshooting methods, not confidential production documentation.
