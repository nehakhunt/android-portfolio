# All Smart Tools

Team-developed Android utility application containing 125+ everyday-use tools.

## Highlights
- Calculators and converters
- Text utilities
- QR/barcode scanning
- Image compression
- Audio recording
- Sensor-based utilities
- Metal detector and accelerometer tools
- Vibration and color detection
- Permission management

**Technologies:** Kotlin, Android SDK, Jetpack, Sensor APIs, Camera APIs

**Reported scale:** 10K+ downloads
