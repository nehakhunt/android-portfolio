# Weather Forecast Alerts

Weather application providing current conditions, forecasts, GPS-based weather, widgets, and configurable alerts.

## Highlights
- Current and daily forecasts
- GPS-based weather
- Customizable widgets
- Temperature, humidity, wind, pressure, and visibility
- Rain and sunrise/sunset information
- Configurable notifications
- Multiple measurement units

**Technologies:** Java, Kotlin, Android SDK, Retrofit, Jetpack, OpenWeatherMap API
