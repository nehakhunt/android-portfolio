# Phone Configuration Checker

Android diagnostics app for inspecting device hardware/software information and running real-time tests.

## Highlights
- CPU, RAM, battery, display, and system information
- Camera, sound, screen, sensor, WiFi, Bluetooth, and GPS tests
- 4G/5G and CPU architecture information
- GPU and application metadata
- 25+ device tests and permission-aware functionality

**Technologies:** Kotlin, Android SDK, Jetpack, Material Design

**Reported scale:** 50K+ downloads
