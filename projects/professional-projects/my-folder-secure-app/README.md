# My Folder: Safe Secure Hidden App

Security-focused Android app for storing and protecting images, videos, audio, contacts, and documents.

## Highlights
- PIN, pattern, and password locks
- Hide/unhide files
- App locking and icon masking
- Recycle bin and storage cleaner
- Shake-to-lock
- Categorized secure folders

**Technologies:** Kotlin, Android SDK, Room, Firebase, Jetpack Components

**Reported scale:** 1M+ downloads; 4.2+ rating
