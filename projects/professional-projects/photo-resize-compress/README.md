# Photo Resize: Compress, Crop

Image utility app for compression, resizing, cropping, format conversion, batch processing, and sharing.

## Highlights
- JPEG, PNG, and WEBP conversion
- Adjustable quality and resolution
- Batch processing
- Non-destructive editing workflow
- Preview, save, delete, and share

**Technologies:** Kotlin, Android SDK, Jetpack, Glide

**Reported scale:** 100K+ downloads; 4.2+ rating
