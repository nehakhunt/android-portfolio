# WiFi Refresh & Signal Alert

Network utility app focused on WiFi scanning, signal monitoring, alerts, and connectivity information.

## Highlights
- WiFi refresh and network scanning
- Signal/RSSI monitoring
- Low-signal, roaming, and no-service alerts
- IP, DNS, MAC, frequency information
- Mobile/WiFi data usage reports
- SIM and nearby-network information

**Technologies:** Kotlin, Android SDK, Jetpack

**Reported scale:** 100K+ downloads
