# Android Architecture

## Experience

My Android development experience includes MVC, MVVM, Android Jetpack, Room, REST APIs, Firebase, background services, and modular application components.

## Typical Flow

```text
UI → ViewModel → Repository → API / Local Database
```

## Key Practices

- Separate UI and business logic
- Use lifecycle-aware components
- Keep data access organized through repositories
- Use Room for structured local persistence where appropriate
- Handle loading, success, and error states clearly
- Keep code maintainable and testable
